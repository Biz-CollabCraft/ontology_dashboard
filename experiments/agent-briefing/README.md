# AI 브리핑 평가 실험 보존

`codex/pr167-ai-briefing-optimization-plan`의 로컬 평가 자료를 선별 흡수했다. 제품 화면·역할 선택·서버 실행 구현·운영 모델 설정은 변경하지 않았다.

- 현재 실행 가능한 비교·등록·Luna 반복·지연 투영·DB 읽기 점검 도구는 `scripts/`에 있다.
- `historical/*.py.txt` 10개는 개인 경로와 당시 임시 입력에 의존하는 원본 소스다. 실행 가능한 Python 모듈로 등록하지 않았다. 자동 실행이나 현재 제품 동작을 보장하지 않는다.
- `source-manifest.json`은 57개 원본의 경로·해시·대상 위치를 기록한다. active 파일은 경로·명시적 실행 모드·평가 상태 복원 때문에 원본과 달라질 수 있다.
- v3/v4/v4.1/v4.2 정답셋은 당시 이름 그대로 보존한다. 최신 v5 기본 평가에 섞지 않는다.
- 과거 원시 모델 응답·출력 JSON·캡처는 기존 로컬 산출물 위치에 남아 있다. 이번 흡수를 그 파일 전체의 백업으로 간주하면 안 된다.
