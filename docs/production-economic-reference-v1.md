# 생산관리자 비용 참고 매핑 v1

파일: systems/frontend/src/features/operations/overview/production-economic-basis.v1.json
계산: referenceEconomics.ts
화면: ReferenceEconomicPanel.tsx

## 사용 범위
요청별 비용 산정 이력이 없는 경우의 **가정 기반 비교 참고**이다.
계약 단가, MES/ERP, 급여 및 확정 견적을 대신하지 않는다.
프론트에서 읽기 전용 계산하며 승인 payload, 저장된 CostAnalysis, 생산 계획 DB를 변경하지 않는다.
현재 데이터가 있으면 기존 상세 생산계획과 저장 비용 산정을 유지한다.
센서별 추이는 생산관리자 메인 중앙에서 제거했으며 개별 영향 상세의 센서는 유지한다.

## 입력과 근거
- CNC 생산능력: 기존 repository의 OEE .846 / 사이클4분 ×60 =12.69개/시간.
- 일일 운전16시간: 기존 데모 2교대 가정. 생산계획 아닌 생산능력이다.
- 개당 생산원가10000원: **명시적 예시 가정**, 현장 ERP 원가 근거 없음.
- 개당 공헌이익5000원: 기존 비용 fixture 가정. 매출 또는 영업이익 아님.
- 정비 인건비17520원/시간: 기존 단가292원/분의 환산. 외부 조사값의 현재 유효성은 재검증하지 못했으므로 내부 참고로 표시.
- 절삭 인서트12453원/개: Haas 2025-10-03 공개 목록 APKT160408 HMP20 10개 소매88.95USD /10 × **가정 환율1400**. 실제 호환·배송·VAT·현재 견적 확인 필요.
- 압축기 소모품100000원/작업30분: **예산 시나리오 가정**, 모델별 실제 견적 없음.
- 압축기 생산 의존4대: 동일 셀 CNC4대·예비 압축기 없음 가정. 실제 설비 토폴로지 확정 아님.

## 계산
시간당 생산원가 = 생산능력 × 개당 생산원가.
시간당 기회손실 노출 = 생산능력 × 개당 공헌이익.
요청 정지 노출액 = 시간당 기회손실 × 요청정지분/60.
정비 인건비 = 정비시급 × 정비작업분/60 (생산 정지분과 별도).
교체비 = 해당 부품을 실제 교체하는 조건에서만 적용.
생산원가와 기회손실을 더하지 않으며 정비가 고장확률을 얼마나 낮추는지 추정하지 않는다.
미입력 정지시간은 v1.1부터 참고 계산에만 CNC30분/압축기60분을 사용한다. CNC는 기존 예방정지 정책30분, 압축기는 준비15+작업30+확인15분의 가정이다. 직접 입력0분은0원이며 음수·NaN은 계산하지 않는다. 실제 요청·승인일정·DB에는 기본값을 저장하지 않는다.

## 검증 예시
CNC10분: 생산능력12.69개/시간, 생산원가126900원/시간,
기회손실63450원/시간, 정지노출10575원, 노출수량3개(올림),
인건비2920원(10분), 인서트12453원, 일일능력203개(내림).
압축기10분: 의존생산4대 가정, 기회손실253800원/시간,
정지노출42300원, 노출수량9개, 인건비8760원(30분), 소모품100000원.
'영향품목 없음'이라고 작성된 경우에도 이 수치는 무완충 정지 노출 시나리오이며 확정 손실이 아니다.
