# 브리핑 근거 연결

## 범위

임의 파일 업로드가 아닌, 설비·이벤트·기준 시각에 맞는 읽기 전용 자료 연결이다.
계정, 비밀키, 로그 전체, 다른 설비의 업무 메모는 브리핑 근거로 보내지 않는다.

|자료|연결 경로|주의점|
|---|---|---|
|센서 관측|gen_data의 정확한 FILE 이벤트 → Result Artifact → 브리핑 패킷|관측 식별자를 유지하며 최신 값으로 몰래 대체하지 않음|
|점검·작업·협의·승인 기록|closed_loop DB → maintenance_history_summary → decision_facts|설비·이벤트·기준 시각 조건을 통과한 기록만 사용|
|생산·자원·품질 운영 정보|operational_context_repository와 planning_context/evidence_context|일치하는 기록이 없으면 미연결 유지, 참고 단가로 실제 계획을 조작하지 않음|
|SOP|data/fixtures/inspection_sop/*.json → 기존 retrieve_inspection_sops|설비 유형·고장 유형·센서 조건 일치 시만 선택. 압축기 절차는 자료 없으면 미제공|
|참고 비용|systems/frontend/src/features/operations/overview/production-economic-basis.v1.json → reference_economics|UI와 동일한 단일 파일. 파일 해시·버전·단위·출처·가정·계산식 전달|

비용표가 인용하는 외부 문헌은 근거 URL과 설명을 전달한다. 호출 때마다 외부 문서를 다운로드하지 않으며 저장소 밖 임의 파일을 읽지 않는다.
참고 비용은 reference_economics에 별도 보존한다. operation_context_summary의 실제 계획·손실 수량을 덮어쓰지 않는다.
정비 노무비·부품비는 특정 교체 작업에 대한 조건부 예시이며 확정 견적이나 전체 설비 교체비가 아니다.

## 계산과 표현

CNC 예: 12.69개/시간 × 10,000원/개 = 126,900원/시간.
30분 요청: 생산원가 환산액 63,450원. 공헌이익 기준 기회노출 31,725원은 별도 시나리오로 합산하지 않는다.
명시적 0분 유지, 음수/NaN은 미산정. 미입력만 CNC 30분/CMP 60분 기본 가정 사용.
기본값은 승인 일정이나 DB 요청 시간에 쓰지 않는다.

생산 관리자 설명에는 시간당 생산원가·정지시간·환산액과 가정/참고 표시를 요구하고 검증한다.
기존 승인/실행 금지와 수량 검증은 유지한다. 모델 버전·권한·데이터 갱신 주기는 변경하지 않는다.
프롬프트 버전 v3.5로 기존 저장본과 구분되며 새 생성이 필요하다. 자동 대량 재생성은 하지 않는다.

## 남는 제약

실제 ERP 원가·생산계획·재고/납기·압축기 SOP가 없는 경우 여전히 미확인이다.
참고 단가표 연결은 이러한 원천 시스템 연결을 완료했다는 의미가 아니다.
