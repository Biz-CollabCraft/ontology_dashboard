## 누락 경로 수정

FILE 관측 브리핑이 센서 근거만 조립하던 경로에 기존 운영 컨텍스트, 근거 선택 및 이벤트 연결 작업 이력을 전달함. 작업 이력 변환 시 원본 asset_id/equipment_id/event_id와 제공된 승인·시작·완료 시각을 보존함. 존재하지 않는 승인 시각은 생성하지 않음.

## 갱신 및 제한

근거가 달라져 과거 저장본은 새 입력의 유효 캐시로 사용되지 않음. 기존 저장본은 삭제하지 않으며 새 요약 생성이 필요함. 외부 모델 호출은 이번 검증에서 수행하지 않았으므로 실제 생성 문장 검증은 별도임.

생산 관리자 승인 일정/메모는 별도 협의 기록임. 작업 상태만으로 승인 시간이나 승인 내용을 추정하지 않으며, 별도 기록의 실제 입력 포함 여부를 추가 대조해야 함. 역할별 표현 차이는 유지하되 동일 근거와 기록 상태를 사용함.
