# 독립 평가자 2명 — 현재 설명의 자동 유용성 검사

현재 제품 방식에서는 LLM이 규칙 기반 설명을 그대로 반환했다. 실제 API 원문 기준 **8/8건의 제목·요약·역할별 설명이 동일**하다. 따라서 이 실행에서는 LLM을 추가해 설명이 개선되었다는 증거가 없다. AI의 일반적인 유용성이나 다른 설계의 가치를 부정하는 결론은 아니다.

## 고정한 범위

- 기존 합성 Gold 사건 8개, 현재 로컬 코드 및 실제 입력 전문 보존.
- OpenAI API gpt-4o-mini를 사건별 1회 호출; 계약 통과 8/8, fallback 0/8.
- 실제 요청과 보존 입력의 일치 8/8, 생성 중 코드·계약·fixture 해시 변화 없음.
- LLM에 baseline 초안을 제공하는 현재 제품의 prose-editing 경로를 평가한다. 독립 생성, 새로운 holdout 또는 전체 UI 사용성 검사가 아니다.
- 두 평가자 각각 순서를 바꾼 별도 맥락에서 평가. 동일 기본 모델이며 모델 계열 다양성은 없다. 같은 사건의 네 판정은 독립 표본 네 개가 아니다.

## 무엇을 유용성으로 보았나

설명만 읽고 ‘먼저 무엇을 확인할지’, ‘왜 확인할지’, ‘무엇을 아직 확정할 수 없는지’를 파악할 수 있는지 평가했다. 평가자는 사실 충실성 및 세 질문에 0/1/2를 부여하고 핵심 근거를 인용했다. 이는 **LLM이 평가한 텍스트의 과제 지원 정도**이며 사람의 이해도, 판단 시간, 현장 성과는 미측정이다.

## 평가자 검사용 사례

정상 동일 설명, 잘못된 수량, 필수 한계 누락의 3쌍을 사건에 섞었다. 단순 우열뿐 아니라 오류 종류를 잡았는지 검사했다. 정답은 채점 후 공개했다. 이는 작은 탐지 능력 검사이며 인간 평가 일치도를 검증한 것은 아니다.

| 평가 세션 | 검사용 사례 통과 |
|---|---:|
| judge1-forward | 3/3 |
| judge1-reverse | 3/3 |
| judge2-forward | 3/3 |
| judge2-reverse | 3/3 |

원천과 출력이 같아도 source의 모호성 또는 중요한 한계 판단이 달라질 수 있다. 순서/평가자 간 불일치나 indeterminate를 동률로 강제 변환하지 않고 보류했다.

## 결론과 다음 판단

이번 구성으로 설명의 근거 충실성, 정보 누락, 과제 지원에 대한 **자동 예비 점검은 가능**했다. 검사용 오류 탐지와 순서 일관성을 함께 관찰할 수 있었다. 그러나 LLM의 추가 유용성은 입증하지 못했다. 두 경로의 텍스트가 동일하기 때문에 판단 시간 개선이나 더 나은 설명을 주장할 수 없다.

현재 prompt는 완성된 baseline을 주고 사실을 보존하며 필요한 문구만 편집하도록 한다. 실제 응답은 모든 사건에서 그 초안을 복사했다. 과거 저장 출력과 달리 새 실행에서 수량·생산 영향 계약 위반이 없었지만, 한 번의 8건 실행이 생성 오류율의 일반적 개선을 증명하지는 않는다.

다음 설계 판단은 ‘LLM에게 맡길 추가 과제가 무엇인가’다. 여러 근거의 충돌 설명이나 역할별 대안 비교가 필요하다면 그 과제를 별도로 정의한 후 새 후보로 비교한다. 결과를 좋아 보이게 하기 위해 이번 입력·출력을 수정하거나 모델 출력을 다시 뽑지 않았다.

## 준비 오류와 제한

첫 평가 자료에서 ontology_context를 빠뜨려 근거가 있는 부품 문구가 근거 없음으로 판정됐다. 이는 평가 준비 오류이며 해당 결과는 invalid-projected-source-attempt에 보존하고 집계에서 제외했다. 생성 결과는 바꾸지 않고 원천 전체로만 다시 평가했다. 평가 기준·검사용 사례·합의 규칙은 유지했다.

이전 개발에 사용한 사건, 단일 생성 반복, 동일 계열 평가 모델, 알려진 간단한 검사용 사례, 미측정 인간 일치도라는 한계가 있다. 평가 모델의 정확한 버전을 별도 provider ID로 고정하지 못했으므로 완전한 반복 재현도 보장하지 않는다.

## 실행 비용의 범위

생성 API 보고 토큰 합계 47,328, 생성 8건의 측정 시간 합계 30.78초. 평가 에이전트 사용량과 최종 청구 비용은 이 수치에 포함하지 않았다. 이 시간은 사용자 판단 시간과 관계없다.
