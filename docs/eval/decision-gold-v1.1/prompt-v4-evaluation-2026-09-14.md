# v4 프롬프트 평가 — 2026-09-14

정보 누락에 대한 명시적 근거 기준은 두 모델에서 제안 라벨과의 일치를 개선했다. Luna의 전체 6항목 일치도도 개선됐지만 의미 분류는 악화됐다. 4o-mini의 불필요한 보류는 증가했다. 전 항목 개선 또는 품질 검증 완료로 결론 내리지 않는다.

## 비교 방법

v1.1 평가 분할 중 제안 라벨이 있는 20문장 × 3회 × 2모델 = 120개 새 v4 응답을 수집했다. API 요청은 모델별 9회, 총 18회다. 미정 D05-03, D05-04, H05-03, H05-04는 제외했다. 개발 분할은 사용하지 않았다. 에이전트 검수를 거친 합성 초안이며 사람/현장 검수 골드가 아니다. 이미 관찰·수정에 사용한 문장이므로 개발/회귀 결과다.

v3 기준값은 이전에 저장한 응답을 동일한 v1.1 라벨로 재채점했다. v3를 새로 호출한 동시 대조 실험은 아니다. 입력 원문 20개, schema, 모델별 설정은 같고 실행 로직은 프롬프트와 버전 이름 외에 변하지 않았음을 확인했다. 모델 호출 시간 차이와 반복 변동 가능성이 있어 차이를 프롬프트의 인과 효과로 단정하지 않는다. 같은 문장 3회는 독립 사례 60개가 아니다.

## 남은 불일치와 판단

- 정보 누락은 둘 다 60/60으로 일치했다. 새 측정 요청이나 모호한 지시에서 누락을 추론하지 말라는 보강 방향은 이 회귀 세트에서 효과가 관찰됐다.
- Luna는 D05-01/H05-01의 선택 가능한 측정을 meaning=new_measurement로 분류했다. 제안 라벨은 clear_other다. optional 상태와 측정 필수=false는 유지돼 행동 제약은 맞았지만, 의미 분류의 회귀를 숨기지 않는다.
- D03-04/D06-04 등에서 unclear와 not_stated 경계의 불일치가 남았다. 모호한 지시와 명확한 비측정 해석의 구분이 완전히 안정됐다고 볼 수 없다.
- 4o-mini는 D05-02를 3회 모두 근거 충돌로 추가 분류해 보류했다. v3에서 불필요 보류가 1회였던 사례이므로 이번 실행에서는 악화됐다.
- v4를 모든 모델에 개선된 버전으로 일괄 승인할 근거는 없다. Luna는 전체 6항목과 정보 누락에서 개선되고 행동 제약을 유지했지만 의미 항목 회귀가 있다. 이번 점수를 보고 추가 프롬프트/라벨 변경이나 반복 재시도는 하지 않았다. 기본 서버 모델 설정도 바꾸지 않았다.

## 검증과 증거

신규 응답 120개를 합성 read-only 도구와 실제 LangGraph에 재생했다. 사람 승인 필요, 도메인 mutation 미시도, 정책상 허용 action 범위가 모두 유지됐다. 단일 추천 순위 정확도, tool path 정확도/불필요 호출, 운영 성능을 채점한 것은 아니다. 기존 v3 행동 제약은 이전 재생 기록이며 v1.1에서 행동 제약이 변하지 않았음을 기준으로 비교했다.

고정 소스 해시가 실행 후 일치했고, 두 모델의 입력·schema 해시도 9쌍 모두 일치했다. 원문·라벨·프롬프트는 실행 중 변경하지 않았다. v1.1 원본의 검수 상태는 pending 48개이며 구조 검증 오류는 0이다. 이전 턴의 78개 오프라인 테스트 통과와 이번 실제 모델 평가는 별개의 증거다.
