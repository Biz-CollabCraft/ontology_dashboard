# AI 브리핑 판단 유용성 예비 검증

## 목적

Direct LLM 출력과 Pipeline 출력을 같은 로컬 fixture A/B 조건에서 비교해, 브리핑이 다음 조치 판단에 필요한 정보를 더 안전하게 제공하는지 예비 검증했다. 이 문서는 발표에 사용할 수 있는 수치와 사용 범위를 정리한다.

## 발표용 핵심 수치

| 검증 항목 | Direct | Pipeline | 차이 |
|---|---:|---:|---:|
| 입력→화면 제공 안정성 계약 | - | 40/40 (100.0%) | Pipeline 계약 검증 |
| 내용 검사 통과 후보 반환율 | 25/120 (20.8%) | 97/120 (80.8%) | +60.0%p |
| 판단 유용성 예비 자동평가 완전 통과율 | 0/120 (0.0%) | 18/120 (15.0%) | +15.0%p |
| 블라인드 에이전트 선호율 | 7/24 (29.2%) | 17/24 (70.8%) | +41.7%p |


입력부터 화면 제공까지의 안정성은 별도 계약 테스트로 확인했다. 8개 fixture마다 입력 해시 재현성, 기준 시각 유지, 선택 근거 전달, ViewModel/summary context 전달, 화면 표현 준비 계약을 확인해 40개 조건이 모두 통과했다.

## 발표 문장

메인 성과는 다음 문장으로 사용한다.

> Direct LLM과 Pipeline을 같은 8개 fixture, 120회 조건에서 비교했을 때, 내용 검사 통과 후보 반환율이 20.8%에서 80.8%로 개선되어 +60.0%p 차이를 보였다.

보조 검증은 다음 문장으로 사용한다.

> 같은 A/B 출력을 라벨 없이 에이전트 3명이 검수했을 때, Pipeline 브리핑이 24표 중 17표, 70.8%에서 더 유용하다고 선택됐다.

필요하면 자동평가 수치를 다음처럼 덧붙인다.

> 판단 유용성 예비 자동평가에서도 Pipeline은 완전 통과율 15.0%로 Direct 0.0% 대비 +15.0%p 높았다.

## 해석

Pipeline의 강점은 브리핑을 바로 반환하지 않고, 근거 범위·상태 구분·금지 주장·독자용 표현을 검사한 뒤 통과한 후보만 제품 출력으로 넘긴 점이다. 특히 작업요청 승인 여부, 기준 시각 이후 기록 제외, 재고·착수·완료 미확인 같은 상태 경계에서 Direct보다 안전한 출력을 더 자주 만들었다.

자동평가의 완전 통과율은 낮게 잡는다. 이 평가는 6개 조건을 모두 만족해야 통과하는 보수적 기준이며, 실제 현장 사용자 평가가 아니다. 발표에서는 `+60.0%p`를 메인 성과로 두고, `70.8% 선호`를 판단 지원 가능성의 보조 증거로 사용한다.

## 검사 범위와 한계

- 입력은 로컬 fixture 8개, 각 15회 반복이다.
- 모델은 gpt-5.6-luna 조건의 기존 A/B 산출물을 사용했다.
- 블라인드 평가는 사람 현장 담당자가 아니라 에이전트 3명의 예비 검수다.
- 실제 운영 KPI, 다운타임 감소, 정비 성공률, 사용자 생산성 개선으로 확대 해석하지 않는다.
- 사람 사용자 평가를 하려면 동일한 블라인드 샘플을 보전·공정·생산 역할 평가자에게 제시하고 선호율과 위험 단정 지적률을 별도로 수집해야 한다.
