# Generator Runtime Prediction Result Batch Examples

이 디렉터리는 `systems/generator`의 Runtime Prediction Result Batch 및 Model Prediction Result 규격을 나타내는 예시 자산을 포함합니다.

- `prediction-results.json`: `generator-model-prediction-result.schema.json`을 준수하는 모델별 score 및 실행 상태 결과 배열 예시
- `prediction-result-batch.json`: `prediction-result-batch.schema.json`을 준수하는 Generator -> Backend handoff payload 예시
